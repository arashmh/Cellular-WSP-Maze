Maze-Hard: 1,000 of 1,000

The 1,000 test mazes of Maze-Hard (30 × 30, every shortest path 110 cells or longer), run in your browser by the network itself. One path, as scored runs the Maze-Hard edition: the 115-weight program plus a pointer register that picks the benchmark’s path, 208 non-zero weights of 3,027 numbers. Every shortest path runs the 115-weight automaton unchanged. Click any square of the grid to run that maze.

Left: the share of the 1,000 test mazes solved against the number of weights (log scale); teal is this work, orange the agent-written looped transformer of Looped Weight-Space Programming, grey the trained reasoners as compiled there. Right: how many shortest paths each test maze has. The mazes are the test split of sapientinc/maze-30x30-hard-1k, packed into maze-hard/maze-hard-data.js. Neither the dataset’s answer nor breadth-first search is ever given to the cells.

Cellular Weight-Space Programming · Arash Moaddel, Ashkan Moaddel, Nina Uller · ibiLAB. The weights were programmed directly in weight space by Claude Opus 5.5 (Anthropic) in Claude Code, with no training.
